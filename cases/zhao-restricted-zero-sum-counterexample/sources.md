# Sources

## Primary source

Kevin Zhao, “On zero-sum subsequences in a finite abelian group of length not exceeding a given number,” arXiv:2506.21383, Conjecture 6.1.

- [arXiv abstract](https://arxiv.org/abs/2506.21383)
- [arXiv PDF](https://arxiv.org/pdf/2506.21383)

The source statement used by this package is the version identified as Conjecture 6.1 in the cited preprint.

## Standard input

The identity

$$
D(C_2\oplus C_4^3)=D^*(C_2\oplus C_4^3)=11
$$

is the standard Davenport-constant formula for finite abelian $p$-groups. The counterexample argument itself is reproduced in full in this directory.
