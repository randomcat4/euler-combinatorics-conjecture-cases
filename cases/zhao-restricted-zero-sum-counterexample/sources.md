# Sources

## Primary source

Kevin Zhao, “On zero-sum subsequences in a finite abelian group of length not exceeding a given number,” arXiv:2506.21383.

- [arXiv abstract](https://arxiv.org/abs/2506.21383)
- [arXiv PDF](https://arxiv.org/pdf/2506.21383)

The source statements used by this package are Definition 1.1, Conjecture 1.2, Theorem 1.9, Theorem 1.11, the remark after Theorem 1.11, Lemma 1.7(iii), Conjectures 6.1, 6.2, and 6.4 in the cited preprint.

## External exact value

Alexander Sidorenko, “On generalized Erdos-Ginzburg-Ziv constants for `Z_2^d`,” arXiv:1808.06555.

- [arXiv abstract](https://arxiv.org/abs/1808.06555)
- [arXiv PDF](https://arxiv.org/pdf/1808.06555)

This package uses Sidorenko only for the exact value `s_4(C_2^7)=15`, via Theorem 5.6 and the exact-value table for `d=7`.

## Standard inputs

The identity

$$
D(C_2\oplus C_4^3)=D^*(C_2\oplus C_4^3)=11
$$

is one instance of the standard Davenport-constant formula for finite abelian $p$-groups. The same formula is used for `C_n^4`, `C_2^2 direct-sum C_4^2`, `C_2^7`, `C_2^8`, and `C_2^12`.

All counterexample arguments and finite witnesses are reproduced in this directory. No non-public document is redistributed.
