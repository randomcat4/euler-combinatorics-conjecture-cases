# Sources

## Primary Source

Huiqiu Lin and Da Zhao, "Comparison between the first Steklov eigenvalue and
algebraic connectivity on trees", arXiv:2508.13466v1.
[arXiv](https://arxiv.org/abs/2508.13466v1).

The public case uses Conjecture 1.3 in Section 1, physical arXiv v1 PDF page 3.
It also uses Definition 2.4 and Lemma 2.5 for the definition and displayed
value of the extra-special tree.

## Related Work Boundary

The source paper's Theorem 1.2 proves an adjacent upper bound in the
matching-number class, but not the sharper extra-special value used in
Conjecture 1.3.

Related public Steklov-tree sources on fixed leaf count and total vertex count,
edge stretching, degree/leaves bounds, or diameter constraints do not settle
this matching-number \(b=3\) slice.

## Priority Boundary

The supporting public-source audit found no same-conclusion or stronger public
result for the \(b=3\) matching-number slice, but the public priority status
remains `NOT_ESTABLISHED`.
