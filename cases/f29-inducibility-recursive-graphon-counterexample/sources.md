# Sources

## Primary Source

Levente Bodnar, Jun Gao, Jared Leon, Xizhi Liu, Oleg Pikhurko, and Shumin Sun,
"The inducibility of 6-vertex graphs," arXiv:2606.00290v3.

- [arXiv abstract](https://arxiv.org/abs/2606.00290v3)
- [arXiv PDF](https://arxiv.org/pdf/2606.00290v3)

The source statement used here is Conjecture 4.7 on physical PDF page 29. The
recursive graphon definition is in Section 4 on physical PDF page 26, and the
induced-density normalization is stated earlier in the paper.

## Boundary Inputs

The target graph is

```text
F29=(6,{03,04,13,15,45}).
```

The graphon witness uses six equal-measure parts, binary off-diagonal cells,
and recursive diagonal cells under the convention described in the source.

All counterexample data and verification code are reproduced in this directory.

research log is redistributed.
