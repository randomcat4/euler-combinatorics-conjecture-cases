# Sources

## Primary Source

Nawaf Shafi Alshammari, Sergey Kitaev, and Artem Pyatkin, "On the
representation number of grid graphs and cylindric grid graphs,"
arXiv:2507.16469v1.

- [arXiv abstract](https://arxiv.org/abs/2507.16469v1)
- [arXiv PDF](https://arxiv.org/pdf/2507.16469v1)

The source statement used here is Conjecture 1 in Section 4, Open problems, on
physical PDF page 10. The relevant definitions are word representation,
`k`-word representation, representation number `R(G)`, and toroidal grid graph
`TGr_{m,n}=C_m square C_n`.

## Boundary Inputs

At `(m,n)=(3,5)`, the toroidal grid is `TGr_{3,5}=C_3 square C_5`. Since `C_3`
is a triangle, the graph has 15 vertices and 30 edges: five column triangles
and three row 5-cycles.

All counterexample data and verification code are reproduced in this directory.
