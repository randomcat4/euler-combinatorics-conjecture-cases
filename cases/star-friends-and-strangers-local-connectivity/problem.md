# Source problem and exact claim

Primary source: [Krishnan--Li, arXiv:2410.21334v1 and v3](https://arxiv.org/abs/2410.21334v3). Locator: Conjecture 8.1 in v1, renumbered Conjecture 7.1 in v3.

Every connected FS(X,Star_n) and every pair of distinct configurations have exactly the minimum endpoint degree internally vertex-disjoint paths, including adjacent endpoints.

The [proof](proof.md) defines all objects and covers the full claim. The result type is `COMPLETE_SOLUTION`. Executable finite checks have only the scope described in [verification](verification.md).
