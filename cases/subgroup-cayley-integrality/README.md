# Subgroup normality and Cayley integrality

**Source problem:** [Poddar--Biswas--Das, arXiv:2511.14496v1](https://arxiv.org/abs/2511.14496v1), first unnumbered open issue of Section 6; Definition 1.4, Section 2 and Theorem 3.1.

**Result: `COMPLETE_SOLUTION`.** For every finite group G of order at least five and every proper nontrivial subgroup H, Gamma_H(G) is integral if and only if H is normal.

A nonnormal subgroup supplies an irreducible coset constituent with a proper nonzero fixed space. A genuine two-dimensional Cayley adjacency block then has two irrational eigenvalues; an unbounded square-gap argument proves this for every permitted parameter.
