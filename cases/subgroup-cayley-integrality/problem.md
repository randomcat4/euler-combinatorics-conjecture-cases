# Source problem and exact claim

Primary source: [Poddar--Biswas--Das, arXiv:2511.14496v1](https://arxiv.org/abs/2511.14496v1). Locator: first unnumbered open issue of Section 6; Definition 1.4, Section 2 and Theorem 3.1.

For every finite group G of order at least five and every proper nontrivial subgroup H, Gamma_H(G) is integral if and only if H is normal.

The [proof](proof.md) defines all objects and covers the full claim. The result type is `COMPLETE_SOLUTION`. Executable finite checks have only the scope described in [verification](verification.md).
