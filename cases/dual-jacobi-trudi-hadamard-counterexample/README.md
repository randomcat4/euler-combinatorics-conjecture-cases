# A distinct-shape Hadamard dual Jacobi--Trudi counterexample

**Source problem:** [Angarone--Kim--Oh--Soskin, arXiv:2511.08969v1](https://arxiv.org/abs/2511.08969v1), Conjecture 1.2 in Section 1; identity-diagram determinant in Section 2.3.

**Result: `COUNTEREXAMPLE`.** Conjecture 1.2 is refuted by the order-three determinant for (18,18,15)/(2,0,0) and (20,18,18)/(2,2,0); the specified ordinary monomial coefficient is negative. Same-shape Conjecture 1.1 is not settled.

Six exact coefficient products sum to -1288935568443079606185991333432800. The coefficient is reconstructed by elementary-variable assignments, exact dynamic programming and a closed multinomial sum.
