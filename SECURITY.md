# Security and disclosure boundary

Do not commit credentials, access tokens, private keys, live infrastructure endpoints, local machine paths, session identifiers, unpublished correspondence, or personal data.

This public archive intentionally excludes operational research logs and internal coordination records. Reproducibility information is limited to mathematics, source code, stable dependencies, commands, and outputs needed to check the public claims.

If sensitive material is committed accidentally, rotate affected credentials immediately and contact the repository owner to arrange history cleanup.
